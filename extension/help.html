Pinpoint setup

Click an element in your browser, say what should change, and your coding agent does it.

1. Start the bridge

Keep this running in a terminal while you work — it is what connects the browser to your agent.

cd pinpoint/bridge
npm install
node cli.js --project /path/to/your/app

The popup's status dot turns green once it can see the bridge. Port 7331 by default; use --port and the popup's "Bridge port" field if something else has it.

2. Connect your agent

Claude Code — register it, then let annotations arrive by themselves:

claude mcp add pinpoint -s user -- node /ABS/PATH/pinpoint/bridge/cli.js mcp
node /ABS/PATH/pinpoint/bridge/cli.js install-hooks /path/to/your/app

The second line adds two hooks to your project's .claude/settings.json. After that you never have to mention Pinpoint: whatever you have marked in the browser rides along with your next message. Existing settings are preserved.

Cursor — .cursor/mcp.json

{ "mcpServers": { "pinpoint": { "command": "node", "args": ["/ABS/PATH/pinpoint/bridge/cli.js", "mcp"] } } }

Codex — ~/.codex/config.toml

[mcp_servers.pinpoint]
command = "node"
args = ["/ABS/PATH/pinpoint/bridge/cli.js", "mcp"]

Anything else: MCP over HTTP at http://127.0.0.1:7331/mcp, or read .pinpoint/pending.md in your project, or use Copy prompt and paste into any chat.

3. Annotate

A small bar appears in the corner of every page while the bridge is running — that is Pinpoint telling you it is live in this tab. Click it, or press ⌥⇧A (Alt+Shift+A on Windows/Linux).

Then click an element, type the change, and press ⌘↩ / Ctrl+Enter. Comment mode stays on, so the next note is just another click — press Esc when you have finished. The bar's counter opens a list of everything marked on this page; its × hides it for that site, and the toolbar popup brings it back or moves it to another corner.

A numbered pin stays on the element until your agent marks it done, at which point it disappears on its own — that is how you know the change has been made.

Useful commands

node cli.js status                 # running? how many pending?
node cli.js print                  # pending annotations as markdown
node cli.js resolve <id>           # mark one done by hand
node cli.js clear                  # delete everything
node cli.js --help
